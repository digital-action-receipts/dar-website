# Control mapping

| Control area | Case-study evidence | Status |
|---|---|---|
| Authorization and attribution | manifest scope, approvals, prohibited actions, human transition | Partial / case-study only |
| Change traceability | starting commit, implementation commits, evidence update commits | Locally verified |
| Secure development | tests, secret scan, dependency audit, SAST, headers, SBOM, diff check | Locally verified and CI corroborated |
| Release integrity | PR head, workflow run, artifact digest | Externally corroborated |
| Privacy and retention | synthetic-only boundary and explicit exclusions | Not implemented |
| Authentication, RBAC, storage, backups | outside scope | Not verified |
