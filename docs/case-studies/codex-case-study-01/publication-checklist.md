# Publication checklist

- [ ] Snapshot version is `1.0.0` and starting commit/ancestry are recorded.
- [ ] Implementation/evidence commits, remote head, PR, run, timestamps, and SBOM digest are recorded.
- [ ] Manifest and verification-report digests are recorded.
- [ ] Evidence classifications are applied consistently.
- [ ] Public report removes sensitive paths, prompts, identifiers, secrets, and unnecessary metadata.
- [ ] Enterprise report includes scope, approvals, lifecycle, validation, corroboration, privacy, retention, controls, and limitations.
- [ ] Reviewer guide and questionnaire are complete.
- [ ] All repository tests, instrumentation tests, security checks, SBOM, and diff checks pass.
- [ ] PR remains draft; no merge, deployment, settings, secret, or infrastructure action occurred.
